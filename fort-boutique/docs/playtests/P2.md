# Playtest P2 — les dix premières minutes (M11)

Date : 2026-10-21 (UTC). Build : `dist-test/index.html` de M11. Détail des mesures : `P2.measures.md` et `.json`.

## Méthode
1. `npm run playtest -- P2` : jsdom, vrais touchers, robot « au rythme humain » (`scripts/lib/human-bot.mjs`, temps de lecture fixes,
   DECISIONS.md). Deux parties de plus : un **joueur hésitant** (8 s sans bouger, arrêt après la première prise, voleur ignoré) et un
   **joueur passif la nuit** (immobile, jamais de Cloche).
2. Captures 360 × 640 dans Chromium (`scripts/screens.mjs` : enveloppe, indices du jour 1, Rush, Commande spéciale, voleur).
3. Critiques de Léa (14 ans), Hugo (17 ans) et Sam (34 ans), à partir des mesures, des captures et du code (agents en lecture seule,
   avec scripts de reproduction). Les vérifications croisées et la revue de code automatique ont été coupées par la limite d'usage :
   chaque constat a été reproduit à la main avant d'être corrigé.

## Ce qui plaît
- **Léa** : enveloppe qui s'ouvre d'un tap n'importe où ; main fantôme et flèche dorée dès 0:06 ; « RUSH! » lisible ; le coffre à taper,
  les cartes qui volent ; l'étiquette d'objectif sans un mot.
- **Hugo** : démarrage sans friction ; voleur à poursuivre (traînée rouge) ; aube « à la Clash Royale » ; gains chiffrés des améliorations.
- **Sam** : aucune pub forcée ; pause automatique et reprise exacte ; un cycle complet tient dans un trajet de 5 minutes.
